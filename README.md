## QuickInvoice

A sellable, no-signup invoice generator lives in [`quickinvoice/`](quickinvoice/).
It's a static web app (no build step, no server) that exports PDF invoices
and sells a $1.99 one-time Pro unlock verified against Gumroad's license
API. See [`quickinvoice/README.md`](quickinvoice/README.md) for how to run
it and how to set up the sale.
